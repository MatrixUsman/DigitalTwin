# Manufacturing comparator screen — 16 October 2026

This is a bounded primary-source screen, with selected manuscript sections and author-code inspection. It is not a systematic review, full reproduction audit, human-reading attestation or benchmark result. Scope: recent manufacturing process/robot anomaly detection controls that could support a cybersecurity study on accessible non-water data. Eligible publication window: 2023-10-16–2026-10-16. No model, notebook, simulator or attack script was executed; no raw dataset was downloaded.

## Decision from this branch of the search

**Original CASPER is a useful manufacturing-specific learning and feasibility lead, but a fair three-method comparison has not been established.** The 2024 CASPER paper and 2025 successor describe different recordings. A 2026 CatBoost article has now been connected to author code reading original CASPER filenames, but that code introduces synthetic labels and preprocessing leakage. The parent audit is checking the direct-twin candidate TWINE (2026); the intended original-CASPER learning set is therefore **CASPER 2024 + TWINE 2026 + CatBoost 2026**, conditional on that audit, with Edge 2025 reserved as related work on a different collection. These candidates are not all twins. Do not turn this learning set into an approved reproduction set.

The Factory I/O quality-inspection paper has six public classifier notebooks and a shared corpus within that paper. That is useful for learning and controls, but **six models in one paper do not equal three recent independent papers**. A production-line simulator with software and recorded observations is also different from a synchronized twin of a physical factory.

## Why the two Kayan papers need a careful common protocol

The corrected 2024 manuscript, Secs. 6.3–6.4, describes scheduled velocity changes and subsequent label alignment using a gyroscope feature. Its preprocessing includes rolling-median filtering, training-fitted normalization and a 755-point period-informed window. Threshold grid search is part of its reported workflow. We have not established a held-out calibration procedure suitable for our project from that description alone.

The 2025 manuscript, Secs. III.D and IV.E, describes 60/20/20 data divisions and grid-searched residual thresholds. It explicitly says disturbance onset/offset timestamps were not recorded; its 265-point aggregation was chosen to obtain windows confidently containing an anomaly. Therefore event-level recall/delay requires a separately defensible annotation rule. Retrofitting precise event boundaries would not be faithful reproduction. New recordings and new disturbance semantics cannot silently replace the earlier corpus.

An original CASPER corpus can still be a common evaluation target for reimplemented/adapted methods, but that would be **our new common-protocol experiment**, not evidence that all three articles originally evaluated the same data. Keep the two assertions separate.

### CatBoost: same original filenames, incompatible target construction

This follow-up supersedes the earlier unsuccessful author-code search. The matching author's portfolio led to his GitHub profile, which links the paper and implementation. We inspected the script rather than accepting the repository's description of its protocol:

- Lines 61–89 load `nicla.csv` (skip six rows) and `right_arm.csv`. The main script does not load the README-listed left-arm or network files.
- Lines 128 and 192 first sample up to 100,000 random rows from each source. The later “stratified sample” helper, lines 458–468, returns unchanged when the input is already at most 100,000. Calling that later helper does not make the first selection stratified.
- Lines 181–182 take right-arm labels from `Anomaly State`. Lines 201–204 explicitly create **synthetic Nicla labels** using the 95th percentile of acceleration magnitude. They do not transfer the documented velocity-manipulation labels.
- Lines 478–484 pad nine IMU columns with zeros and stack them **as additional rows** under the controller-feature columns, while concatenating the two different label definitions. That is not timestamp-aligned multimodal fusion and does not establish common physical feature semantics.
- Lines 492–501 fit a `StandardScaler` to the full assembled matrix before a random stratified 60/20/20 split. This exposes held-out distribution statistics and breaks our train-only preprocessing rule. Random row splits also discard the chronology needed for our intended replay evaluation.
- Line 558 specifies CatBoost with 200 iterations, depth 6 and learning rate 0.1. This can inform a declared independent control, but merely copying that classifier into a corrected pipeline would not reproduce the published experiment.

These observations establish shortcomings in the available script. **Without the full manuscript and authors' exact run revision, we cannot assert that the article's reported numbers came from this precise script.** Admit the paper for critical learning; do not adopt its current code path or headline score as our cyberattack benchmark. A clean CatBoost control on the frozen shared features and authentic labels would be our independent reimplementation under a changed protocol.
