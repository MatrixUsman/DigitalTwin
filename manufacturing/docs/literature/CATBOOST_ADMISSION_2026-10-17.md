# CatBoost on CASPER: comparator admission decision

Audit date: **17 October 2026, Asia/Karachi**. Project: manufacturing; owner: Haiqa Mushtaq. This is an AI-assisted source and implementation audit using the shared academic research skill's bounded verification workflow. It does not attest that a researcher has read the manuscript. No original CASPER observations, fitted models or upstream experiment code were opened/executed in this audit.

**Decision: background / critical-learning paper only for the selected Group D study; exclude the inspected implementation from the main experimental comparison.** Its supervised target construction, observations and random-split protocol differ substantively from our normal-only right-arm motion study. The unavailable manuscript and unresolved code-use permission are additional gaps; obtaining them would not by itself remove the known information-access incompatibility. This replaces an indefinite reproduction hold with a concrete decision for this study, while preserving the option of a separately specified supervised investigation.

## What the published numeric claim can and cannot be traced to

The [official abstract](https://epapers2.org/apscon2026/ESR/paper_details.php?paper_id=6394) reports 97.20% accuracy and F1 0.9718. A new standard-library arithmetic check of the author-stored [run-summary CSV](https://github.com/Priyanshu-byte-coder/CatBoost_Anomaly_Detection_implementation/blob/7f2a691f94f548e6b7c744ee0eeee287489a8639/output2/multi_run_raw_results.csv) found 60 records: six algorithms × ten run IDs. The ten CatBoost test-accuracy values average **0.9719525**, and their F1 values average **0.9718004327472999**, giving the abstract's rounded values. Their separate validation accuracy averages **0.972455**. This verifies numerical correspondence of saved summaries, not observed performance or a reproduction by our project.

The [earlier result-provenance study](../../baselines/catboost/READING_NOTES.md) traced derived tables labelled validation accuracy to the test-accuracy column, differing standard-deviation conventions, and missing generators for later output families. That existing audit is retained as historical evidence; this follow-up did not repeat every derived-table or figure check. Neither abstract agreement nor correct arithmetic supplies the absent sampled row IDs, preprocessing fit state, model hashes, exact run logs or per-observation predictions.

## Final designation and conditions for reconsideration

| Proposed use | Designation now | What would have to change |
|---|---|---|
| Current right-arm, normal-only chronological Group D main comparison | **Excluded; background only.** | A new method with the same eligible inputs and normal-only learning objective would be required. It would not be a faithful reproduction of this supervised classifier. |
| Faithful reproduction of this article | **Not admitted.** | Obtain the complete manuscript, explicit code-use permission, exact release/selected-row/label provenance, configuration and published-run correspondence. Any original evaluation defects must be reported, and upstream test-informed selection cannot become our final protocol. |
| Author code changed to controller-only chronological supervised learning | **Potential separate comparison track, currently not admitted.** | Resolve permission and labels; establish training attack-label access and independent later events/runs in a separately justified protocol. Document all feature, target and split changes as a modified implementation. Do not consume Group D's protected test attacks for training. |
| Fresh CatBoost classifier using a lawful library and a clean independent supervised protocol | **Potential independent implementation in that separate track.** | Specify that new question/data contract and verify library terms/version. It is not this paper's reproduced result. It does not fill a Group D recent-paper-baseline slot. |
| CatBoost used as a normal-only predictor/regressor | **Unspecified new control, not admitted by this paper.** | A regression objective, causal history, score and development-only selection rule would need their own specification. Replacing the classifier objective changes the method. |

Group D's clean prefix supplies no positive training examples, and its later attack intervals are protected final outcomes. Consequently, the present data contract does not admit the supervised alternatives above. We should not weaken that contract solely to retain a third familiar paper.

**The candidate decision is complete for the current scope.** Full-paper learning, reuse permission and published-run reconstruction remain incomplete, explicitly separated from the decision. No paper result is declared false, and no claim of fabrication is made. No digital-twin state model or synchronization mechanism has been established in this classifier implementation. It can inform the literature discussion and motivate disciplined target/input/split audits; its headline score must not enter our main leaderboard.
