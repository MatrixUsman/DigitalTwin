# Implementation — Smart manufacturing

Latest milestone: the [four-score extension](../docs/SCORE_EXTENSION_REPORT_V0.1.md) passed **295 synthetic tests across 46 source/configuration files** and one bounded normal-only replay. C/K/L/Rv are implemented; all six same-state streams cover 160,472 endpoints and reproduce prior R/RC/coordinates exactly. No fitting occurred. Independent internal saved-artifact review passed 257 checks. The attempt is consumed; calibration/final access remains closed.

Earlier observer milestone: [empirical motion-observer validation](../docs/OBSERVER_VALIDATION_REPORT.md) completed once with **254 synthetic tests across 40 source/configuration files**, seven passing internal normal-data checks and a 48-check saved-artifact audit. The paired residual / residual-plus-correction scores share one state trajectory. The supported designation is an empirical observer; AR remains much stronger at one-step prediction, and no attack result or physical-twin validation exists. The observer v0.1 attempt is consumed and must not be replayed. Earlier milestone details below remain historical evidence.

The [full-training control study](../docs/CONTROL_STUDY_REPORT.md) completed one bounded normal-only attempt after **205 synthetic tests passed across 34 source/configuration files**. Seven candidates each used 536,946 eligible training targets and produced 160,472 aligned development scores. Selected artifacts are velocity deviation, the 32-bin periodic template and AR(4) with ridge 0.001; fitted parameters stayed unchanged during development. No calibration or final evaluation ran.

The `mfg_twin` package implements the read-only loader, frozen-metadata development wrapper, causal score/update coordinator and metric primitives. `velocity.py` contains the fixed velocity reference; `controls.py` adds the training-only standardizer, periodic template and causal autoregressive predictor. `control_study.py` coordinates fitting, immutable model artifacts and declared development selection; `supervisor.py` enforces bounded worker execution. These methods are independent ordinary controls, not digital twins or reproduced paper baselines.

The [83-test foundation](../docs/SOFTWARE_VALIDATION.md) and [150-test pilot milestone](../docs/PILOT_REPORT.md) remain historical records. Both the earlier subset pilot and the full-training study have consumed their single declared attempts. The [selected-control registry](../experiments/SELECTED_CONTROLS_V0.1.json) identifies artifacts for later calibration; it is not a completed final-test freeze.

Use the manufacturing-local [environment](../docs/ENVIRONMENT.md). The current package uses only the standard library and is tested with Python 3.15.0. The new `observer.py` and `observer_study.py` implement and evaluate phase state, synchronization and matched scores. The narrow scope and four-score implementation are complete; next admit the full executable roster and calibration-only path. Calibration/final execution still needs its own tested admission path. Do not modify system packages or share mutable runtime state with another project.

Data transformations must preserve chronological and label alignment. No test labels may reach fitting, model selection, threshold calibration or online update gates.

`contract.load_study` verifies the registered data/evaluation metadata without raw access. `iter_development_records` permits only training/development, validates source byte identity before parsing, and can cap a declared prefix. Calibration/final access is deliberately unavailable. `data.iter_csv_partition` is a lower-level parser, not an access-control mechanism. Detectors receive only `Observation`; `EvaluatorRecord` and `ScoredPoint` remain evaluator-only. Pure metric functions require independently verified coordinates and masks.

`observer_scores.py` computes pure validated C/K/L/Rv scores plus exact legacy R/RC. `score_extension.py` replays development with immutable fitted artifacts, complete support and exact historical parity. These additions preserve all earlier source files.

The additive `campaign_data.py`, `campaign_models.py` and `campaign.py` now provide label-free calibration/final feature replay, all eleven frozen deterministic methods, score sealing/admission, exact threshold calibration and separate delayed-label evaluation. Existing fitted-model/metric modules remain unchanged. Final real observations have not been replayed.
