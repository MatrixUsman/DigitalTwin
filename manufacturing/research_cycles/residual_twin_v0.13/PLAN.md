# Command-conditioned residual twin: candidate and normal-only pilot

17 October 2026. The user asks for an actual proposed model after sharing the teacher's review. This implements a candidate under the existing public-data/virtual-simulation scope. The short local run is capped at 120 s wall, 90 s CPU, 1 GiB sampled RSS and 50 MiB outputs. No lengthy neural training, paid compute, new dataset access or attack campaign is authorized by this pilot.

## Scientific question and provisional mechanism

Can a frozen nonlinear correction learned from clean commissioning improve a command-driven reference enough to recognize normal motion under model mismatch, while preventing live measurements from modifying the authorized trajectory?

The base is the already selected stable ARX reference, with orders 8/16/32 for Q1/Q2/Q3. A clean 100-observation prefix initializes its recurrence. Thereafter it uses its own state history and approved commands. Inputs to the residual corrector are the base predicted state and approved commands at lags 1,4,16,32. Means/scales, deterministic farthest-point centers and output weights use training observations only. Gaussian radial-basis activations feed a ridge-fitted four-output linear head. The corrected trajectory is `r_t = r_base_t + state_scale * f(command_history, r_base_t)`.

This is a small machine-learning model, not a transformer or a deep network. The correction never feeds back into the stable base recurrence. RBF activations lie in [0,1], so the fitted correction is bounded for fixed weights. After clean initialization, changing measured observations while holding approved commands fixed cannot change this reference. This is a testable information-flow property, not a proof of accuracy, security or novelty. Compromised approved commands and corrupted initialization are outside scope.

Detection uses the maximum absolute standardized measured-reference residual, with a training-independent normal-calibration threshold. Proposed recovery evidence requires both trailing 5- and 41-observation signed residual means to lie within tolerance 0.1 for ten consecutive eligible observations, with a new entry exceedance taking priority. Unknown command history forces abstention for the remainder of the episode. This gate is a heuristic of normal consistency, not a time-uniform or physical safety certificate. Long and short windows, hysteresis, residual networks and ARX are established methods; their combination is only a candidate until a distinct advantage and prior-art difference are demonstrated.

## Fixed procedure

- Existing synthetic train files: three commissioning episodes per plant. Training targets begin at row100; all correction fits use these same observations. Baseline ARX artifacts are loaded from v0.9, not refitted.
- Development: prior normal calibration episodes0–8, already exposed development material. Evaluate all eight RBF combinations: centers32/64 × width factor0.5/1 × ridge0.001/0.01. Two linear corrections use the identical features and ridge choices. Select independently within each family by worst-episode q99 residual, mean standardized RMSE, parameter count, then identifier. No failed fit may be silently omitted.
- Calibration: prior normal episodes9–13; these were already used in earlier studies and are explicitly reused. Each selected role gets a strict-exceedance threshold at rank ceil(0.99 ×5500). Calibration changes thresholds only; it cannot choose models, windows or gates.
- Seal all fitted artifacts, candidates, selection and thresholds before generating new normal tasks K13/L13/M13. Their exact parameters, seeds and conditions are in config.json. Three tasks × three plants × three seeds × three normal conditions =81 episodes. Conditions include unchanged motion, authorized offset and authorized slowdown. They are new parameterizations within the old simulator, not independent robots or final cybersecurity tests.
- Three reference roles: uncorrected selected ARX, selected linear correction, selected RBF correction. Same inputs, state scales and initialization. For each role report point-return, 41-window return and dual-window return diagnostics. Do not force the proposed role to win by selecting a favorable reported subset.
- Output: normal prediction RMSE, q99 measured residual, frozen-threshold benign alarms, return-evidence fraction and forced-latch probe success, plus all selected parameters, failures and measured cost. Diagnostic probes begin at100/320/620/900 and allow250observations, requiring ten consecutive qualifying points. They test normal clearing opportunity, not post-attack recovery.
- Primary pilot criterion: the nonlinear correction must reduce pooled normal prediction RMSE against the uncorrected ARX on every plant, without increasing pooled q99 residual on any plant. Report this criterion unchanged. It is an internal reference-feasibility gate, not novel-detector validation. No automatic redesign/retry follows a failed result.

## Tests and provenance

Synthetic tests must check training-only fitting, deterministic centers, future isolation, absence of live-observation inputs in the correction, exact save/reload parity, constant/nonfinite channels, invalid history, causal return windows, missing inputs, entry priority, dwell and no mutation. They use explicitly synthetic fixtures, not benchmark results. Freeze code/configuration, permitted input hashes, upstream dependencies, passing test receipt, Python/dependencies and prior package identities before the single pilot. The existing supervisor records resource consumption and preserves failures. Verification recomputes saved scores/metrics and checks all artifacts in a fresh process without refitting.

## Later validation required

Five research questions organize later experiments: reference-model selection; fair attack detection on brief/persistent deviations; physical-recovery and premature-clear outcomes; legitimate changes and noise/model mismatch; component ablations and computational cost. The present run addresses the normal-reference part only. A new attack study requires a separate frozen plan with every baseline/ablation and fresh conditions. CASPER/Edge normal-IMU architectural runs remain a separate information track; TWINE and CatBoost cannot be silently admitted as normal-only baselines. Global optimal parameters, state-of-the-art superiority and publication-ready novelty are not established by this plan.
