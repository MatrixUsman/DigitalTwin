The candidate's falsifiable engineering proposition is narrower: a frozen, command-driven nonlinear correction may reduce nominal reference error without permitting subsequent measured motion to move that reference. We test the reference error and information isolation. An original contribution would require a precise distinction from protected residual models, an advantage over matched simple/learned controls, and fresh attack/recovery evidence. The proposed dual-window gate is an ablation candidate; averaging and alarm hysteresis are not new.

This is our independent implementation. No code or learned weights from these papers are presented as used in the pilot. Existing simulator/ARX code and source hashes are bound in FREEZE.json; no third-party benchmark results are copied into a numerical ranking.
