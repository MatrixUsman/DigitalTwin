## FAIL-Detect manuscript-to-code findings

Pinned repository revision: `b758e55f7c0c988188f2e4876ffc03ae8a3c30ed`. Root code license is CC BY-NC 4.0; inspected source is retained locally, not republished. `UQ_test/plot_with_CP_band.py` calls `FunctionalPredictor.get_one_sided_prediction_band`; `functional_predictor.py` implements the upper-band nonconformity as score minus predicted mean. The arXiv v1 appendix prints the opposite sign. Thus the manuscript discrepancy must not be presented as a demonstrated failure of the executable upper-band method. The one-sided code uses an interpolated `np.quantile`; its finite-sample corrected rank is commented out. Our restricted variant uses the explicit finite-sample rank on 19 episode maxima. This is a disclosed protocol change using standard conformal mathematics, not a novel invention. The unused LCP file is not the paper's selected executable path and imports Gurobi; it was not executed or installed.

The numerical study uses new synthetic recordings, not original robomimic/real-robot releases. It supplies the same eligible observation/command inputs to the common score and freezes calibration before outcomes. It does not inherit whole-trajectory coverage under fixed task/plant distribution shifts. No published result is copied into the comparison table.

## Contribution admission before outcomes

Precise testable candidate: clean-commissioning reference plus uncertainty-aware clearance, measured against same-plant counterfactual recovery and a matched learned-reference hysteresis control. Its operational assumptions and ablations are explicit. **Algorithmic novelty is not established** by this review. Possible evidence contributions are a rigorously separated recovery target, a reproducible mismatch experiment, and a quantified benefit or failure of the specified clearance rule. A journal-ready original-method claim must depend on the actual comparative findings and resolution of close prior art, not on renaming this engineering combination.
