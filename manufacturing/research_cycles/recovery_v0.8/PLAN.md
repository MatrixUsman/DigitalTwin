# Recovery under model mismatch: prospective study v0.8

17 October 2026. The user authorizes contribution development, fair virtual experiments and a publication manuscript. Existing v0.1–v0.7 artifacts remain immutable. This local prospective protocol is not external preregistration. No physical equipment, paid compute, publication or dataset upload is involved.

## Question and contribution candidate

Can a command-driven reference identified during clean commissioning reduce mismatch-related alarms while retaining evidence until the attack-induced motion deviation disappears? Distinguish (1) plant deviation from its own uncorrupted counterfactual, (2) deviation from an approximate nominal model, and (3) ending command corruption. These are distinct evaluation targets.

The proposed mechanism uses a frozen, command-driven ARX counterfactual reference plus a separately calibrated prediction-error allowance when clearing an alarm. Reference propagation never follows post-initialization measurements. A clean commissioning assumption is explicit. The mechanism is compared with the exact same learned reference using ordinary hysteresis and with a zero-allowance ablation. System identification, uncertainty tubes and dwell rules are established; this study does not presume that combining them is a novel algorithm. A successful result would support the narrower commissioning/recovery design and its conditions. Novelty admission requires the accompanying prior-art review.

If x^0 is the same plant's uncorrupted counterfactual, r the learned reference, y=x+n, and ||x^0-r||_s <= b, ||n||_s <= eta, the triangle inequality bounds attack-induced distance by max(0,||y-r||_s-b-eta) and ||y-r||_s+b+eta. This conditional fact motivates the return test; empirical calibration does not make b a deterministic bound. Neither Gaussian noise nor held-out trajectory shifts receive a safety guarantee.

## Information and fitting

Three new simulated plants vary masses, damping, actuator lag and geometry. Each supplies three separate, known-clean commissioning trajectories, with all three methods given the same y=(q,qdot), protected command u and availability. The generator's true parameters/state and attack schedule never enter a detector. Fit an ARX(4) on standardized y and four command lags, intercept unpenalized, ridge 1e-7 on mean normal equations. Fitted mean/scale use commissioning only. No order/ridge/architecture search. Require homogeneous spectral radius <1; instability is a preserved failure, not silently repaired.

Free-running reference starts from the first four measured observations, then uses only preceding predicted states and approved commands. The four-sample startup is excluded; all primary methods share a 100-sample warmup. The predictor comparator uses observed history instead. Nominal physics/observer controls retain the original specified nominal model; all receive approved commands. Missing command context makes command-dependent decisions unknown for the remainder of that episode, since a held command cannot reconstruct the unobserved command history. This conservative choice is common to methods, reported as coverage loss and not counted as correct negatives.

For each plant, calibration uses 19 fresh, normal episodes with predetermined task parameters and authorized offsets/slowdowns. Calibration never selects models. The scalar learned-reference error is max absolute standardized channel discrepancy. All main alarms select the smallest observed score threshold yielding at most 1% alarmed eligible calibration observations for the whole state machine. A constant reference allowance b is the maximum scalar error across these 19 calibration episodes. This is an empirical envelope; under exchangeable independent episode scores it coincides with a 95% split-conformal order statistic, but the fixed scenario design here does not establish exchangeability. No unconditional 95% claim is permitted.

Methods: persistence; ARX one-step; following-observer point; following-observer hysteresis; nominal-reference hysteresis; nominal-reference fixed-return; learned-reference point; learned-reference hysteresis; learned-reference fixed-return; learned-reference uncertainty-aware return (candidate); learned-reference whole-episode CP threshold (separate calibration-budget track). Add same-entry-threshold candidate ablations removing the allowance and removing dwell. Keep all thirteen methods. No neural retraining is needed for this isolated mechanism test.

Candidate clears after ten consecutive valid samples with scalar learned-reference discrepancy + b <= 0.1. This uses the already established training-scale tolerance. b includes nominal measurement error empirically; it is not a deterministic separate sensor bound. Alarm entry exceeding the calibrated high threshold takes priority. The zero-allowance ablation uses discrepancy <=0.1. Ordinary hysteresis uses half its entry threshold. CP point threshold uses the maximum whole-episode score over 19 calibration episodes; it is a restricted independent implementation of functional-CP thresholding, not the full FAIL-Detect model or its guarantee under shifted tasks.
