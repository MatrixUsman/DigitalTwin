Fixtures are explicitly synthetic functions in the test modules, generated in memory or temporary directories; no real observations are copied into the repository. From manufacturing, run `.venv/bin/python scripts/run_synthetic_tests.py`. The runner records a source snapshot, log and receipt, blocks raw paths/network through a process-local audit hook, and needs no third-party packages. Supervisor tests use reviewed toy subprocesses and require local process monitoring; the harness audit hook is process-local and does not propagate into those children. The managed sandbox blocks `ps`, so the recorded suite used approved local execution. Synthetic checks never establish benchmark performance. Add domain-specific physical-consistency checks only where their assumptions are justified.
