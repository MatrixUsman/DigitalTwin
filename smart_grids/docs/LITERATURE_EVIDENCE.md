# Smart-grid literature evidence register

Screened **2026-10-16**. This is a bounded initial screen, not a systematic review, full paper audit, or reproduction. Primary publisher/institutional records and accessible author-manuscript text were checked. No paper PDF, dataset, or code repository was downloaded. Search failures mean **unverified**, not absent.

Main-paper window: **2023-10-16–2026-10-16** inclusive; prefer 2024–2026. Both candidates below fall within it by journal publication. Neither is yet approved as a main comparison; their electrical settings and control tasks differ.
