## CAROTS: manuscript evidence

The method combines CUTS+ causal discovery, causality-preserving/disturbing synthetic augmentation, and contrastive learning. It assumes time-invariant normal causal relations; confounding and changing relations remain limitations. This is a relevant anomaly-detection comparator, not evidence of an adaptive digital twin.

The manuscript reports SWaT and WADI; 20% of normal training data is validation; training-based standardization; factor-five downsampling; length-ten windows; an anomalous label if any retained point is anomalous. It reports AUROC, AUPRC, and best F1, averaged over three seeds. Checkpoint selection uses validation loss; point-adjusted F1 is explicitly excluded. Defaults described include 30 epochs, batch 256, and an NVIDIA A40. CAROTS-dagger removes the forecasting-error ensemble term, using only the contrastive score; Table 1 evaluates both variants on both datasets. Exact provider release IDs, file checksums, and all implementation dependency versions are absent from the inspected manuscript. [Full manuscript, §§3.2, 4.3, 5.1, Table 1 and Appendices A/B/D](https://arxiv.org/html/2506.03964v1).

## IT-DT: manuscript evidence and gaps

The accessible [full manuscript](https://arxiv.org/html/2603.01621v1) describes N4SID, steady-state Kalman updates, and Gaussian KL residual scoring. It claims identification from seven normal SWaT days and fourteen normal WADI days; model orders 12/25; window 60 selected from 30/60/120/240; regularization `1e-4`; and a 99th-percentile threshold from attack-free validation. It partitions test data into ten chronological subsets for significance analysis. Exact releases/files, checksums, sensor/control mapping, scaling, missing-value handling, validation timestamps/size, test intervals, point adjustment, seeds, and executable dependencies are not specified sufficiently for reproduction.

Its window sensitivity description uses F1 and ten validation folds while threshold calibration is described as attack-free; the source of positive validation labels needs clarification. Reported limitations include Gaussian approximation and false positives during operational transitions. Algorithm 1 corrects the state before the alarm decision; **our inference** is that its stated synchronization is not itself a gate preventing state correction from suspect observations. State estimation and online parameter adaptation must be distinguished. No verified adaptation-poisoning experiment was found. (§§III–VI; Algorithm 1.)

No author repository or code license was identified through the arXiv record/manuscript or exact-title searches with `github`, `code`, and `DOI`. Status: **not located**, not “code does not exist.” Publisher/proceedings verification remains **unavailable/not found**. Full manuscript access succeeded. The paper's numerical claims have not been independently verified and are intentionally not treated as project results.

## Recommendation and bounded next step

**Prioritize CAROTS among these two**, conditionally: it has verified proceedings publication, both target datasets, and inspectable author code. Include both full CAROTS and CAROTS-dagger (no ensemble) in the predeclared reproduction plan; do not choose between variants using held-out attacks. First resolve dataset release identity, SWaT label alignment, preprocessing, device/dependency compatibility, and the forbidden test-based threshold/reporting paths. The workspace compute audit reports no CUDA, so unmodified execution is blocked locally; a CPU/MPS port would require documented implementation changes. Then propose a short, explicitly budgeted pilot. Preserve original source, record patches, and describe the resulting evaluation as an **author-code reproduction with declared protocol changes**; do not promise numerical replication of oracle-F1 results.

Keep IT-DT as a relevant preprint lead. Before promoting it to a principal reproduction target, obtain or verify code and the missing protocol details. If unavailable and later implemented from the manuscript, label it our reimplementation. Neither source establishes novelty for the provisional trust-gating research question.
